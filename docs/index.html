Roller Splat 2D

A swipe-to-paint puzzle game: the ball slides straight until it hits a wall, painting every tile it rolls over. Paint 100% of the floor before time runs out to clear the level and earn up to 3 stars. A solo project covering the full cycle: design, code, tests, UI and effects.

Gameplay

What the game does

A complete game loop, from the loading screen to the win/lose popups, with saved progress and settings.

👆

Swipe & keyboard controls

Swipe with mouse or touch, or use the arrow keys / WASD. Even very fast flicks register: the direction is resolved in the same frame the finger lifts.

🎨

Paint the whole board

The ball glides along the grid in one continuous motion, and every tile it passes takes the paint colour. The progress bar updates in real time; 100% wins.

⏱️

Timed levels & 3 stars

Each level can have a time limit. Finish with ≥ 2/3 of the time left for 3 stars, ≥ 1/3 for 2 stars; run out and the lose popup offers a retry.

✨

Game feel / “juice”

  • The ball stretches while sliding, then squashes and wobbles when it hits a wall
  • Paint drops spray away from the wall, and a sparkle trail follows the path
  • Floor tiles pop and flash white, rippling along behind the ball
  • Win fireworks that scale to fit any level size
⏳

A loading screen with personality

The scene loads asynchronously while a ball rolls along the progress bar, painting it and flicking paint drops behind it. The bar never runs ahead of the real load.

💾

Menu, settings & save data

The menu shows the level you will continue from. A shared Settings popup has volume sliders, a progress reset with confirmation, and a Home button. Data is saved with PlayerPrefs.

📱

Responsive camera

The orthographic camera sizes itself to fit any level on any aspect ratio, with extra padding in portrait.

🧩

10 Tilemap levels

Levels are painted with Tilemap and the Tile Palette. Each level is one prefab with its own floor colour, paint colour and time limit.

Engineering

Engineering highlights

The focus is code that is easy to test and extend, with a clear separation of responsibilities.

🧠

Logic decoupled from Unity

GridModel, SwipeTracker, LevelTimer are plain C# classes with no MonoBehaviour dependency, so EditMode tests cover them and run in milliseconds.

📐

Grid movement, no physics

No Rigidbody2D. The slide path is computed up front by scanning walkable cells, then animated by a coroutine with an ease-out. The ball always stops exactly on a cell centre, so it can never drift off the grid.

📡

Event-driven communication

OnSwipe, OnSlideEnded, OnCellPainted, OnProgressChanged, OnWon/OnLost… References are assigned in the Inspector, with no Find* calls.

🧪

Test-Driven Development

34 tests cover the grid, slide paths, swipes (including fast flicks), the level loader, camera fit, the timer and star rating, and save data. Save tests swap the key prefix so real player data is never touched.

🛠️

Editor tooling

Editor scripts build the Loading, Menu and Game scenes and their UI from code, so a scene can be rebuilt in one click with no manual setup mistakes.

🎛️

New Input System

Reads Keyboard.current / Pointer.current directly; a small state machine handles press → drag → release for both mouse and touch.

Architecture

Architecture & data flow

One responsibility per script. Here is how a single swipe flows through the components:

SwipeInput — keys / swipe → direction
OnSwipe(dir) ↓
BallController — gets the path, slides via coroutine
GetSlidePath / PaintCell ↓
GridManager → GridModel — tilemap ↔ grid logic, paints cells
OnCellPainted · OnProgressChanged ↓
PaintCellEffects · BallEffects · UIManager — effects & HUD
IsComplete / LevelTimer ↓
GameManager — OnWon / OnLost → popup, save progress, LevelLoader.LoadNext()
// GridModel.cs — the heart of the gameplay
public List<Vector3Int> GetSlidePath(
    Vector3Int start, Vector3Int dir)
{
    var path = new List<Vector3Int>();
    if (dir == Vector3Int.zero) return path;

    var next = start + dir;
    while (walkable.Contains(next))
    {
        path.Add(next);
        next += dir;
    }
    return path;
}

// LevelTimer.cs — star rating from the time left
public static int ComputeStars(float remaining, float limit)
{
    if (limit <= 0f) return 3;
    float left = remaining / limit;
    if (left >= 2f / 3f - 1e-4f) return 3;
    if (left >= 1f / 3f - 1e-4f) return 2;
    return 1;
}
