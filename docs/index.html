Gameplay

Những gì game làm được

Một vòng chơi hoàn chỉnh từ màn hình loading tới popup thắng/thua, có lưu tiến trình và tuỳ chỉnh.

👆

Điều khiển vuốt & bàn phím

Vuốt bằng chuột/cảm ứng hoặc phím mũi tên/WASD. Nhận cả những cú “flick” cực nhanh — hướng được tính ngay trong frame thả tay.

🎨

Sơn kín màn chơi

Bóng trượt liền một mạch theo lưới, mỗi ô đi qua đổi sang màu sơn. Thanh tiến độ cập nhật realtime; đủ 100% là thắng.

⏱️

Level tính giờ & 3 sao

Mỗi level có thể đặt giới hạn thời gian. Còn ≥ 2/3 thời gian → 3 sao, ≥ 1/3 → 2 sao, hết giờ → popup thua & chơi lại.

✨

Game feel / “juice”

  • Bóng kéo giãn khi trượt, squash & wobble khi đập tường
  • Bắn giọt sơn ngược hướng tường, vệt lấp lánh theo đường đi
  • Ô sàn “pop” + flash trắng, lan dần theo sau bóng
  • Pháo hoa khi thắng, tự scale theo kích thước level
⏳

Loading screen có hồn

Load scene bất đồng bộ; quả bóng lăn trên thanh progress, sơn thanh và bắn giọt sơn. Thanh không bao giờ chạy trước tiến độ load thật.

💾

Menu, Settings & lưu game

Menu hiển thị level đang chơi tiếp, popup Settings dùng chung (âm lượng, reset tiến trình có xác nhận, nút Home). Lưu bằng PlayerPrefs.

📱

Camera responsive

Camera orthographic tự tính size để vừa mọi level trên mọi tỉ lệ màn hình, có padding thêm cho màn dọc (portrait).

🧩

10 level bằng Tilemap

Level dựng bằng Tilemap + Tile Palette kéo thả, mỗi level là 1 prefab với màu sàn/màu sơn/thời gian riêng.

Interactive

Chơi thử luật game ngay trên web

Bản mô phỏng nhỏ bằng JavaScript, dùng đúng thuật toán trượt như GridModel.GetSlidePath trong game Unity.

Engineering

Điểm nhấn kỹ thuật

Ưu tiên code dễ test, dễ mở rộng và tách biệt trách nhiệm rõ ràng.

🧠

Logic tách khỏi Unity

GridModel, SwipeTracker, LevelTimer là C# thuần — không phụ thuộc MonoBehaviour — nên test được bằng EditMode test, chạy trong mili-giây.

📐

Di chuyển theo lưới, không physics

Không dùng Rigidbody2D. Đường trượt được tính trước bằng cách dò ô walkable, rồi nội suy mượt bằng coroutine với ease-out. Bóng luôn dừng đúng tâm ô — không có bug lệch vị trí.

📡

Giao tiếp bằng C# event

OnSwipe, OnSlideEnded, OnCellPainted, OnProgressChanged, OnWon/OnLost… Tham chiếu gán qua Inspector, không dùng Find*.

🧪

Test-Driven Development

34 test cho grid, slide path, swipe (gồm flick nhanh), loader, camera fit, timer/sao và save data. Save test đổi key prefix để không đụng dữ liệu thật.

🛠️

Editor tooling

Viết Editor script tự động dựng scene Loading/Menu/Game và UI từ code — dựng lại scene chỉ bằng 1 click, tránh lỗi thao tác tay.

🎛️

Input System mới

Đọc trực tiếp Keyboard.current / Pointer.current; một state machine nhỏ xử lý press → drag → release cho cả chuột và cảm ứng.

Architecture

Kiến trúc & luồng dữ liệu

Mỗi script một trách nhiệm. Luồng một lượt vuốt đi qua các thành phần như sau:

SwipeInput — phím / vuốt → hướng
OnSwipe(dir) ↓
BallController — lấy path, trượt bằng coroutine
GetSlidePath / PaintCell ↓
GridManager → GridModel — tilemap ↔ logic lưới, sơn ô
OnCellPainted · OnProgressChanged ↓
PaintCellEffects · BallEffects · UIManager — hiệu ứng & HUD
IsComplete / LevelTimer ↓
GameManager — OnWon / OnLost → popup, lưu tiến trình, LevelLoader.LoadNext()
// GridModel.cs — trái tim của gameplay
public List<Vector3Int> GetSlidePath(
    Vector3Int start, Vector3Int dir)
{
    var path = new List<Vector3Int>();
    if (dir == Vector3Int.zero) return path;

    var next = start + dir;
    while (walkable.Contains(next))
    {
        path.Add(next);
        next += dir;
    }
    return path;
}

// LevelTimer.cs — xếp hạng sao theo thời gian còn lại
public static int ComputeStars(float remaining, float limit)
{
    if (limit <= 0f) return 3;
    float left = remaining / limit;
    if (left >= 2f / 3f - 1e-4f) return 3;
    if (left >= 1f / 3f - 1e-4f) return 2;
    return 1;
}
